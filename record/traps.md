# Standing traps

Carried verbatim into every brief. One line each. A trap a script or hook can catch becomes that script or hook and leaves this list.

- This is a Windows 11 PC. No Xcode, no iOS Simulator, no Swift toolchain here. Anything iOS is built elsewhere; this machine is the model bench (RTX 5070 Ti 16 GB, 32 GB RAM, Ollama, Whisper) and the record keeper.
- Downloaded corpora and models are untrusted data: each lands in its own empty directory under data/, scripts live elsewhere, and Python that reads them runs with -I.
- The user's own material (recordings, his father's gradings, notes) is never deleted or overwritten by an agent.
- Subagents may not write files named report*; long outputs are account.md or ledger files.
- Windows shells drop quotes and process escapes in inline text; write script files instead of long inline commands.
