## Fact 1. Nile-Chat and other Egyptian LLMs

### 1a. Nile-Chat (MBZUAI-Paris) - EXISTS
- Source: model card, MBZUAI-Paris org on HF. Class: model-card. Read 2026-10-31. Reached by guessing HF id, then search "Nile-Chat Egyptian Arabic Latin script Arabizi LLM arXiv".
- URL: https://huggingface.co/MBZUAI-Paris/Nile-Chat-4B
- Ids seen: MBZUAI-Paris/Nile-Chat-4B (4B, base google/gemma-3-4b-pt), MBZUAI-Paris/Nile-Chat-12B (12B dense, base google/gemma-3-12b-pt), MBZUAI-Paris/Nile-Chat-2x4B-A6B, MBZUAI-Paris/Nile-Chat-3x4B-A6B (MoE, 6B active per name).
- License: "License: gemma" (both 4B and 12B cards). Weights BF16.
- Quote: "Nile-Chat models are based on Gemma 3 models."
- Latin-script claims: "developed to handle both scripts commonly used in Egypt: Arabic script and Latin-based Arabizi." and "a compact 4B parameter model that balances efficiency and fluency, well-suited for generating Egyptian Arabic in both Arabic and Latin scripts."
- 4B benchmarks (zero-shot): Arabic-script avg 57.85 (EgyptianHellaSwag 68.56, EgyptianPIQA 55.92, EgyptianAlpacaEval 86.95); Latin-script avg 51.38 (EgyptianPIQA 65.32, EgyptianHellaSwag 50.55). Translation (long, short): BLEU 37.49 / 30.35, chrF 58.40 / 52.01, BERTScore 84.30 / 74.07. Transliteration: BLEU 51.46, chrF 80.44, BERTScore 89.59.
- 12B card: Transliteration described as "Transforming a sentence from Egyptian (written in Arabic script) to Arabizi (Written in Latin script) and vice-versa." Translation covers Egyptian Arabic script, MSA, English; no prompt format given. Latin-script example prompt "Esmak eh?".
- Paper: "Nile-Chat: Egyptian Language Models for Arabic and Latin Scripts", arXiv 2507.04569 (submitted 2025-07-06), ArabicNLP 2025 (ACL Anthology 2025.arabicnlp-main.25, pp. 306-322). Class: paper. URL https://arxiv.org/abs/2507.04569 ; html https://arxiv.org/html/2507.04569v1 . Authors: Guokan Shang, Hadi Abdine, Ahmad Chamma, Amr Mohamed, Mohamed Anwar, Abdelaziz Bounhar, Omar El Herraoui, Preslav Nakov, Michalis Vazirgiannis, Eric Xing.
- Abstract quote: "uniquely designed to understand and generate texts written in both Arabic and Latin scripts." and "our 12B model yields a 14.4% performance gain over Qwen2.5-14B-Instruct on Latin-script benchmarks."
- Paper details (html v1): Arabizi defined as "both Arabic script and a Latin-based script commonly referred to as Arabizi or Franco-Arabic". Paper gives only "3" for ع and example "7aga gameda"; no full digit mapping; transliteration prompt (App. C.1) asks for "Egyptian Latin Script (Franco-Arab)" with no mapping. Translation prompt adapted: "the translation should be written using the Latin script", but NO separate results for English-to-Latin-script translation reported (Latin tables cover understanding tasks).
- Latin training data: "used Claude to transliterate a portion into Latin script" -> 255M Latin-script words; instruction data translated into Egyptian and "processed into the Latin script"; target "roughly 25%" Latin. Limitation quote: "the model occasionally generates hallucinations"; because Claude did translation, output "may not fully capture the unique nuances of Egyptian Arabic."
- Context check: assumed lead is CONFIRMED but releaser is MBZUAI-Paris (MBZUAI's Paris lab); sizes 4B/12B plus two MoE variants.
