# Egypt Talk: wave app-4 plan (2026-10-31): hold to talk, Apple English, translate fallback, prefix cache

1. Files changed: MicCapture.swift (hold routing: while held, raw tap buffers go to a sink and the segmenter is reset and skipped; 0.5 s mute plus reset after release; utterances carry their end time), Transcriber.swift (translate-only with an English promptTokens prefix; transcribe-Arabic second pass; Speaker, Heard and the detection pass deleted), AppModel.swift (Routing deleted; hold begin/end; top path translate / fallback-apple / dropped; TIME lines), ContentView.swift (switch deleted; bottom half is the hold surface with a held state and live heard line), LlamaEngine.swift (KV prefix reuse), NileChatPrompt.swift (fixedPrefix split, same rendered text), SessionLog.swift (millisecond time helper), project.yml (NSSpeechRecognitionUsageDescription), ios-build.yml (print that key), FIRST_RUN.md section 7.
2. New file: EnglishListener.swift. SFSpeechRecognizer(en-US), requiresOnDeviceRecognition, SFSpeechAudioBufferRecognitionRequest fed the native-format tap buffers, partials to the heard line, final on endAudio(). Chosen over SpeechAnalyzer: no asset-inventory flow, takes native buffers, every symbol checked in Apple doc JSON (none deprecated on iOS).
3. Gesture: DragGesture(minimumDistance: 0) with @GestureState on the whole bottom half. GestureState resets on end AND on cancel, so a stolen touch cannot leave the top half suspended. Bottom ScrollView is scroll-disabled (programmatic scroll to newest stays). A 60 s cap and backgrounding also end a hold.
4. Prefix cache: tokens decoded so far are remembered; each request tokenizes the full prompt exactly as before, keeps the longest common token prefix, llama_memory_seq_rm(mem, 0, keep, -1), decodes only the rest. Correct by construction even if the cut tokenizes differently; warmed at load with BOS + fixedPrefix (cut after the instruction's "\n\n", before `English: "`). On seq_rm false: full clear and full decode.
5. Translate check: NLLanguageRecognizer.dominantLanguage(for:) == .english and no Arabic script, else (Apple pack installed) Whisper transcribe ar + AppleTranslator, else dropped with escaped raw in the log.
6. Likely break 1: Speech framework Sendable/isolation diagnostics (handler closures capturing the request and recognizer, called on the main queue). Mitigation: Swift 5 mode; handler hops through Task { @MainActor }; MicCapture sink is a plain closure under an NSLock.
7. Likely break 2: SwiftUI gesture plumbing (GestureState.updating signature, onChange two-argument form, scrollDisabled) in a view that receives the model through EnvironmentObject. Mitigation: only iOS 17+ forms already used elsewhere in this file.
8. Likely break 3: C interop in the cache path (llama_memory_seq_rm returns Bool; llama_pos is Int32; array slice to UnsafeMutablePointer for llama_batch_get_one). Mitigation: decode from a fresh Array copy via withUnsafeMutableBufferPointer, as the existing code does.
9. Runtime risks: on-device English assets missing (shown as a status line, bottom half then inert); NL misjudging very short English (costs a second pass, does not show wrong text); input format change mid-hold.
10. Not done: streaming arabizi (optional), any change to phrasebook.json.
